Infuse Academy — embeddable player

Everything below the line is a single iframe. Host this file on any domain; nothing else needs configuring.

The snippet

<iframe src="https://infuse.bryanharrigan.dev/embed"
        width="100%" height="640"
        style="border:0" allowfullscreen></iframe>

Options

  • ?course=<courseId> — open on one course, skipping the catalog
  • ?q=leadership — pre-filter the catalog
  • ?theme=dark — dark surface for dark host pages

What it does

  • Browsing and searching the catalog needs no login.
  • Absorb credentials are asked for only when a learner presses play, and are typed into the Absorb domain inside the frame — never into this page.
  • Playback access is enforced by Absorb at launch, not by this page.
  • No API key, portal URL, or secret appears anywhere in the snippet.
Demo harness for the Infuse Academy embed. The host page holds no credentials and no configuration.
