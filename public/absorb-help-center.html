Aura Admin Assist

Updated 17 days ago

Aura Admin Assist is an AI assistant in the Admin Experience. Administrators can ask it how to do something in Absorb, or ask it for supported LMS data in plain language. This article covers how it works, what it can answer, where it stops, and the usual troubleshooting steps.

Chats with Aura Admin Assist are free and do not consume credits. The Aura Credits System Overview article explains how credits work elsewhere in Aura. Admin Assist is currently English only.

Aura Admin Assist Configuration

Aura Admin Assist is on by default in some portals. If it is not enabled in yours, a System Administrator can switch it on in Client Settings. Your Account Manager can help if Aura is not available in your portal at all.

To reach the Aura configuration tile, an Admin needs the User Management > All permission in their User Settings.

Admin
 ON This user will be able to access the admin portal.
User Management

In the Admin Experience, follow these steps to enable Aura Admin Assist:

  1. Click Client Settings in the Account menu.
  2. Open the Aura tile.
  3. Switch Admin Assist on and save.

Understand Responses

Source Citations

Answers drawn from Absorb documentation carry a citation back to the article they came from, so an Admin can confirm the source rather than take the answer on trust.

Live LMS Data

Data questions are answered against the portal's live records, scoped to what the signed-in Admin is already permitted to see. Admin Assist cannot widen its own permissions.
