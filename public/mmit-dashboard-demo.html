What this proves
Selecting a deliverable makes this portal ask Absorb one question: has
this analyst completed the methodology course that governs client-ready
output? The answer is what locks or clears Export above — the same call
your own system would make before letting a file leave the building.

Three outcomes, not two. If Absorb cannot be reached the verdict is
unknown, which still holds the export but is shown differently:
telling an analyst they are uncertified when the truth is that a call
failed is its own bug.
